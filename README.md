# luowen-assets

Long-term static assets for Luowen brand materials.

## Logo Files

| File | Use case |
| --- | --- |
| `brand/logo/luowen-logo-white-transparent.png` | White transparent logo for dark backgrounds. |
| `brand/logo/luowen-logo-white-on-dark-preview.png` | Preview version with a dark background. |
| `brand/logo/luowen-logo-dark-transparent.png` | Dark transparent logo for light backgrounds. |

## Recommended URLs

If GitHub Pages is enabled without a custom domain:

```text
https://YOUR_GITHUB_USERNAME.github.io/luowen-assets/brand/logo/luowen-logo-white-transparent.png
https://YOUR_GITHUB_USERNAME.github.io/luowen-assets/brand/logo/luowen-logo-white-on-dark-preview.png
https://YOUR_GITHUB_USERNAME.github.io/luowen-assets/brand/logo/luowen-logo-dark-transparent.png
```

If a custom image domain is added later:

```text
https://img.YOUR_DOMAIN.com/brand/logo/luowen-logo-white-transparent.png
https://img.YOUR_DOMAIN.com/brand/logo/luowen-logo-white-on-dark-preview.png
https://img.YOUR_DOMAIN.com/brand/logo/luowen-logo-dark-transparent.png
```

Avoid using `raw.githubusercontent.com` links for long-term public brand assets.
